## 2. Где вендоры РАЗОШЛИСЬ — это развилки, а не шум

### A. Прямой API vs OpenRouter — главная развилка
- **Gemini:** идти **только через OpenRouter** — европейская Visa/MC без KYC, один ключ на все лаборатории, снимается вопрос хранения промптов.
- **Grok:** №1 = **прямой** `api.deepseek.com/anthropic` (нативно и дешевле), OpenRouter — лишь вариант №3; у посредника своя ToS и комиссия ~5.5%.
- **ChatGPT/Codex:** прямой endpoint подтверждён документацией, **но** приём обычной карты ЕС у DeepSeek напрямую — «**не гарантировано официально**», публичной гарантии Visa/MC для всех стран ЕС нет.
→ Развилка настоящая: Grok топит за цену и нативность, Gemini — за платёжную и приватностную определённость, ChatGPT подтверждает ровно ту дыру, которую лечит Gemini.

### B. Coding-plan подписка vs pay-as-you-go
- **Grok:** Z.ai GLM Coding Plan Lite (~$12.6–18/мес) = вариант №2.
- **ChatGPT/Codex:** тот же Lite $18/мес — но «**base allowance публично не раскрыт**», то есть покупаем кота в мешке.
- **Gemini:** ⛔ **не брать coding-plan вообще**: headless-агент делает десятки невидимых микро-вызовов в минуту, жёсткие лимиты (80–400 промптов / 5 ч) выжигаются за одну сессию отладки, и лаборатория встаёт на 5 часов.
→ Возражение Gemini операционно самое сильное именно для нашего сценария и сходится с арифметикой ChatGPT ($25 PAYG = 28.7M выходных токенов).

### C. Открытые ли веса у DeepSeek V4 — прямое противоречие
- Gemini: «Да (MIT)». · Grok: «❌». · ChatGPT: «не подтверждено для V4».
→ 2 из 3 не подтверждают. **Считаем неподтверждённым**, на самохост V4 не закладываемся.

### D. Цена GLM-5.2 PAYG — ложное совпадение
- Grok и Gemini дают одинаковые $1.40 / $4.40.
- ChatGPT: это цена **GLM-5.1** с захваченной прайс-страницы; официальной строки PAYG для **5.2** в доступной версии прайса **нет**.
→ Классический [[false-corroboration-two-sources-agreeing]]: два вендора «сошлись», потому что оба читали одну и ту же страницу и перенесли цену со старой модели. Считаем цену 5.2 непроверенной.

### E. MiniMax M3 — слабее всех обеспечен
Gemini ставит его №2 ($0.30/$1.20 с промо-скидкой 50% на OpenRouter), Grok — №3 (Token Plan Plus $20), ChatGPT прямо говорит «актуальные цены M2.5/M3 **не подтверждены**, как основной review-API не брать».
→ Берём в третью очередь, не в первую.

## 3. Рекомендация (моя, как кофаундера)

**Брать DeepSeek V4-Pro на PAYG как 4-ю пару глаз. Подписку сейчас НЕ покупать.**

Порядок на один вечер, ≤$15:
1. Сперва **OpenRouter** ($10–15 европейской Visa) — это тест платёжной рельсы, которую ChatGPT пометил как негарантированную у DeepSeek напрямую.
2. Параллельно попробовать **прямой** `api.deepseek.com/anthropic` с малым топ-апом. Прошла карта → остаёмся на прямом: дешевле и нативный Anthropic-endpoint без посредника.
3. Обёртка `ds-review.sh` отдельным env — основной Claude Code не трогаем (сосед `secondop.py`, как рельса Grok).
4. Промпт-роль: adversarial code review, «найди баги, недостающие тесты, где проще».
5. Хард-кап $25 + лог трат.

**Вторая волна (не сейчас):** GLM-5.2 — только если DeepSeek начнёт слишком часто соглашаться с Grok. Критерий Grok'а хороший: меряем не Elo, а долю расхождений.

**Границы, которые все трое подчёркивают:** в китайскую рельсу уходят только диффы кода со снятыми секретами. Ни волта, ни CRM, ни клиентского/NDA-кода. По умолчанию промпты прямого API могут идти в обучение.

⛔ **Деньги = Tier-2.** Ничего не куплено и не оплачено. Решение и кнопка — за Антоном.
